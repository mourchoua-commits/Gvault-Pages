# Note #3 - 2026-11-20 : Monde vivant v3 musical dans Chat Studio

Chaîne : note #1 -> note #2 -> note #3.

## Ce qui a changé
- `chat-studio.html` mis à jour : le mini-jeu **Monde vivant** devient **v3 musical** directement dans le Chat Studio (plus de page à part).
- **Chaque matière joue une note différente** (gamme pentatonique, 26 matières = 26 notes).
- **Boucle 🎵** : séquenceur 16 bandes, le monde entier devient une boucle de 16 pas à 160 ms.
- Brosse x1 à x5, pause, clear, terrain aléatoire, export PNG.
- **Mode solo** : si personne d'autre dans le salon, un bot peuple le monde pour toi.
- Paint Studio intégré aussi (pads musicaux 🎵), Pong et Morpion 1v1 toujours là.

## Pourquoi
All anonyme voulait un truc simple mais très complexe : un monde vivant qui fait de la musique, jouable en boucle, même tout seul.
