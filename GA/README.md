# GVAULT GA · Projet

Entrée publique : `/Gvault-Pages/GA/`

Ce dossier ajoute une couche projet utilisable autour du jumeau visuel `../GA.html` sans modifier son rendu principal.

Fonctions :
- vue GA intégrée ;
- accès direct à GThink et à l’accueil GVAULT ;
- retour, actualisation, mode focus et plein écran ;
- mémorisation locale de la dernière vue ;
- manifeste web-app et cache de secours du shell.

Le visuel source reste dans `GA.html`. La couche projet est volontairement séparée pour pouvoir faire évoluer l’usage sans dégrader le rendu de référence.
